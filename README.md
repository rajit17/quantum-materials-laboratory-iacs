# Quantum Materials Laboratory website

The deployable site is in [`tqm-lab-website`](./tqm-lab-website/). The root `netlify.toml` points Netlify to that publish directory, so a Git-connected site needs no build command. For a manual deploy, drag the contents of `tqm-lab-website` into Netlify.

Before going live, confirm the academic contact email and current appointment dates with the laboratory. Profile history and publication information are based on the supplied May 2025 CV; the IACS affiliation was updated as requested.
