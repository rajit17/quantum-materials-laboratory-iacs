# Quantum Materials Laboratory website

This dependency-free static website contains separate pages for the home page, research, people, publications, methods, highlights and contact details. All navigation stays within the site; external links open in a separate tab.

## Deploy to Netlify

- For a manual deploy, drag the contents of this folder into Netlify's deploy area.
- For a Git-connected deploy from this workspace root, the root `netlify.toml` publishes this folder. No build command or package installation is needed.
- If setting the base directory to `tqm-lab-website`, use `.` as the publish directory.

The supplied research infographic is stored locally in `assets/`. Profile history, awards and publication details are based on the CV supplied for this project (May 2025); the IACS affiliation was updated as requested. Confirm the current contact address and appointment dates before public launch.
